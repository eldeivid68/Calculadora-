# Calculadora-
David Aguirre - 261134

Calculadora gráfica desarrollada con Java Swing utilizando Apache NetBeans.

## Funciones

* Sumar
* Restar
* Multiplicar
* Dividir
* Calcular raíz cuadrada
* Ingresar números enteros y decimales
* Cambiar entre números positivos y negativos
* Borrar el último número ingresado
* Limpiar la pantalla
* Validar la división entre cero
* Validar la raíz cuadrada de números negativos

## Cómo ejecutar el proyecto

1. Descargar el repositorio mediante **Code → Download ZIP**.
2. Descomprimir el archivo descargado.
3. Abrir Apache NetBeans.
4. Seleccionar **File → Open Project**.
5. Elegir la carpeta que contiene el archivo `pom.xml`.
6. Ejecutar la clase `Calculadora.java`.

## Estructura principal

* `Calculadora.java`: contiene la lógica y los eventos de los botones.
* `Calculadora.form`: contiene el diseño gráfico creado con NetBeans.
* `pom.xml`: contiene la configuración del proyecto Maven.
